# Material availability

The camera-ready article describes public availability of de-identified industrial requirements, generated VCs, expert ratings, prompts, and analysis scripts. This repository's current public release has a narrower scope: numerical records, result summaries, source-derived prompt templates, model-configuration documentation and a public-data-only numerical reanalysis script are public. The text-bearing corpus and the original pipeline and analysis scripts remain withheld.

This statement documents the repository's access scope. It is not a publisher-approved correction to the locked article and does not claim that all materials described there are publicly accessible.

| Material | Public release | Additional access |
|---|---|---|
| Text-free numerical expert ratings | Included, with new identifiers and original missingness | Public files |
| Numerical ablation and generation records | Included within the documented coverage | Public files |
| Aggregate statistics and calculation definitions | Included within the documented coverage | Public files |
| Source-derived prompt templates and model configuration | Included; runtime values and text-bearing examples excluded | Public files; provenance limits are documented |
| Offline numerical reanalysis adapter | Included; reads only the public CSVs | Public files; not the original experiment runner |
| Industrial requirement text and existing/golden VC text | Excluded | Request only; sharing is not guaranteed |
| Generated VC text and text-bearing run logs | Excluded | Request only; sharing is not guaranteed |
| Original pipeline, analysis and redaction scripts | Excluded | Request only; sharing is not guaranteed |
| Original item identifiers, mappings and reviewer notes | Excluded | No public mapping; any request requires separate assessment |

The withheld collection is retained separately under private access. Moving it to private storage does not make it publicly available. No NDA, third-party sharing permission, conference approval, or access entitlement is asserted by this statement.

For material requests, contact Wei Hou, 71275902063@stu.ecnu.edu.cn. Requests are evaluated individually, subject to applicable permissions, confidentiality restrictions, and the availability of the requested material. A reply or approval is not guaranteed.

Withheld text prevents independent checking of the judgments against the underlying requirements and VCs. Withheld pipeline scripts and inputs prevent end-to-end rerunning. These limitations remain even where numerical results can be recalculated from the released records. Providing a request email does not make withheld materials publicly available, and publishing templates or a numerical adapter does not close the remaining discrepancy with the article's broader description.
