# Material Availability

## Public Materials

This repository provides:

- Pseudonymized, text-free evaluation ratings and numerical generation records
- Aggregate experimental results and statistical summaries
- Evaluation criteria and calculation definitions
- Source-derived prompt templates and model configuration metadata
- A Python script for numerical reanalysis

See the [README](README.md) for the file layout and usage.

## Additional Materials
